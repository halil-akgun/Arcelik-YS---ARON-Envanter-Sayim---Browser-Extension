# ARON Inventory Counting Extensions

This repository contains two independent Chrome extensions for authorized service inventory counting:

- `ARON Envanter Sayim 1`: A high-contrast operational interface close to the supplied drafts.
- `ARON Envanter Sayim 2`: A control-center interface focused on summaries and discrepancy tracking.

## Installation

1. Open `chrome://extensions` in Chrome.
2. Enable Developer mode.
3. Select `Load unpacked`.
4. Choose either `ARON Envanter Sayim 1` or `ARON Envanter Sayim 2`.
5. Click the extension icon to open the counting screen.

The extension reads data from `https://6538c6baa543859d1bb1e611.mockapi.io/todos` and stores counting progress in Chrome local storage.
