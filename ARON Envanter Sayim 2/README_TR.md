# ARON Envanter Sayım 2

Sayım farklarını hızlı değerlendirmek için özet göstergeleri bulunan kontrol merkezi arayüzüdür.

Ürün verilerini API'den alır, sayım değerlerini Chrome yerel belleğinde saklar ve barkod okutma, manuel düzeltme, renkli fark kartları, arama, filtreleme ve sıralama işlevleri sunar.
