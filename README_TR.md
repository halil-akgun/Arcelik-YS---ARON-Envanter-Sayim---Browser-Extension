# ARON Envanter Sayım Eklentileri

Bu depo, Arçelik yetkili servis envanter sayımı için iki bağımsız Chrome eklentisi içerir:

- `ARON Envanter Sayim 1`: Taslak ekranlara yakın, yüksek kontrastlı operasyon arayüzü.
- `ARON Envanter Sayim 2`: Özet göstergeleri ve fark takibini öne çıkaran kontrol merkezi arayüzü.

## Kurulum

1. Chrome'da `chrome://extensions` adresini açın.
2. Geliştirici modu'nu etkinleştirin.
3. `Paketlenmemiş öğe yükle` seçeneğine tıklayın.
4. Kullanmak istediğiniz `ARON Envanter Sayim 1` veya `ARON Envanter Sayim 2` klasörünü seçin.
5. Eklenti ikonuna tıklayarak sayım ekranını açın.

Eklenti, verileri `https://6538c6baa543859d1bb1e611.mockapi.io/todos` adresinden alır ve sayım ilerlemesini Chrome yerel belleğinde saklar.
